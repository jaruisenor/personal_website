# Project conventions

- This is Joaquin Ruiseñor's standalone personal website. Keep the repository as source of truth.
- Prefer static Astro with TypeScript, minimal dependencies, semantic HTML, responsive CSS and easily edited content. No agent infrastructure.
- Preserve existing work. Make small, reviewable changes. Document actual development/build/preview commands in README.md when implemented.
- Use only user-approved facts and public sources. Record source URLs and uncertainty in PROJECT_BRIEF.md. Label draft placeholders visibly; never invent employers, roles, dates, achievements or testimonials.
- Public contact is limited to approved LinkedIn and GitHub links. Do not feature projects without user selection or mistake forks for original work.
- Exclude confidential Google details, household, medical and private financial information. Do not inspect Oscar directories, GBrain, personal email, Calendar or credential stores.
- Do not modify jaruisenor.github.io or other existing websites.
- No database, login, CMS, newsletter, analytics or paid service without explicit request.
- Local build and preview first. No remote creation, push, deployment, domain purchase, DNS changes or paid-service connections without explicit approval. Joaquin confirmed ownership of jruisenor.com at Porkbun; hosting and DNS changes still require explicit approval.
- Respect sandbox and approval controls. Run build and relevant checks; inspect desktop and mobile when available. Check keyboard access, contrast, navigation, links, semantic HTML and metadata. Never claim unperformed checks passed.

- Keep the local preview server running during the user’s review and between iterative edits. Stopping it after verification caused reload failures; stop only when requested or when the review session is explicitly finished. Reuse the existing server when available.
